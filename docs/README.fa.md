# مستندات فارسی Peeky

راهنمای کامل نصب، امکانات، پیکربندی، لینوکس، عیب‌یابی و توسعهٔ Peeky در این صفحه نگهداری می‌شود:

- [مشاهدهٔ راهنمای جامع در GitHub Pages](https://ahb1390.github.io/peeky/)
- [مشاهدهٔ سورس همین مستندات](index.md)

برای گزارش مشکل یا پیشنهاد تغییر: [Issues مخزن](https://github.com/ahb1390/peeky/issues).

> برای فعال‌شدن انتشار Pages، در تنظیمات مخزن بخش **Settings → Pages → Build and deployment → Source** را روی **GitHub Actions** قرار دهید. پس از آن workflow مستندات را اجرا کنید.
